# Flappy Papi Bird 🐦

A Flappy Bird-inspired arcade game built using Python and Pygame.

## 🎮 Features

- Bird movement with gravity and flap mechanics
- Randomly positioned pipes
- Continuously moving obstacles
- Collision detection
- Score tracking
- Start screen
- Game-over screen
- Restart functionality
- Increasing game speed every 10 seconds

## 🛠️ Technologies Used

- Python
- Pygame

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Haroon-Sheikh-3/flappy-papi-bird.git
```

### 2. Navigate to the project folder

```bash
cd flappy-papi-bird
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the game

```bash
python main.py
```

## 🕹️ Controls

| Key | Action |
|---|---|
| SPACE | Make the bird flap |
| R | Restart after game over |
